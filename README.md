# L’IA et mes études

Présentation HTML (3 diapositives) — sensibilisation aux avancées technologiques.
Préparé par Dargenton Jérôme, présenté durant la formation Simplon.

## Structure
- `index.html` : les 3 diapositives
- `style.css` : mise en page (s'adapte à la largeur de l'écran)
- `script.js` : lecteur YouTube (chargé au clic sur ▶)
- `assets/` : logos, illustration et photo

## Mettre en ligne avec GitHub Pages
1. Créer un dépôt sur GitHub, puis y déposer tous les fichiers (en gardant le dossier `assets`).
2. Dépôt > **Settings** > **Pages** > Source : *Deploy from a branch* > branche `main`, dossier `/ (root)` > **Save**.
3. Après une minute, la page est disponible à `https://<ton-pseudo>.github.io/<nom-du-depot>/`.
